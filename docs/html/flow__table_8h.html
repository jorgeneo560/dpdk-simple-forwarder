◆ flow_table_track()

void flow_table_track ( struct flow_table *  table,
struct burst_meta *  meta 
)

Step 2 (RX thread): counts the packets of the burst as received.

Adds the TCP and UDP flows to the table and counts each packet in its flow. The flow slot of each packet is saved in meta->slot, so the TX thread can count the packet as sent later. A packet that is not tracked (not TCP or UDP) gets FLOW_NO_SLOT. A packet whose flow does not fit in the table gets FLOW_DROP: the caller drops it.

Parameters
tableTable of the queue.
metaResult of flow_table_filter_burst().

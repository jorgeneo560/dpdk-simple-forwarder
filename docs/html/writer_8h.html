Appends one row per record, all stamped with ts, then flushes.

Row format: "timestamp,src_ip,dst_ip,src_port,dst_port,protocol,rx_bytes, tx_bytes,rx_packets,tx_packets", with the timestamp in Unix seconds with milliseconds.

Parameters
eOpen writer.
tsTimestamp written in every row.
recsRecords to write.

Returns
true on success, false on failure (errno is set; EINVAL for a bad record).

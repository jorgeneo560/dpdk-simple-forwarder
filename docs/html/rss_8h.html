Fills an RSS key with a repeated 16-bit pattern (big-endian).

A Toeplitz key that repeats every 16 bits makes the NIC's RSS hash symmetric: swapping source and destination (addresses and ports) gives the same hash, so both directions of a flow reach the same receive queue.

Parameters
keyBuffer to fill, key[0..len).
lenSize of the key in bytes.
patternThe 16-bit pattern to repeat.

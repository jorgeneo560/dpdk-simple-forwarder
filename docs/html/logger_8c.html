◆ logger_start()

bool logger_start ( const char *  path,
unsigned int  level,
bool  console 
)

Starts the logger thread.

The thread writes log output to a file (appended) and, if console is set, also to stderr. All RTE_LOG output is redirected to it, so callers never block on file I/O. Call after rte_eal_init().

Parameters
pathLog file.
levelLevel for the FLOWFWD log type: 0=error, 1=warning, 2=info, 3=debug.
consoletrue to also print to stderr.
Returns
true on success, false on failure.

Lists the PCI network devices and checks they can be used.

Marks which device is the input and the output port according to cfg, and verifies that at least min_ports devices are bound to a driver DPDK can use (vfio-pci, uio_pci_generic, igb_uio). Skipped when the EAL options contain "--vdev" or "--no-pci". Call before rte_eal_init().

Parameters
argcArgument count of main().
argvArguments of main(), searched for "--vdev" and "--no-pci".
min_portsNumber of usable devices required.
cfgConfiguration with the input and output port ids.
Returns
true on success, false on failure.

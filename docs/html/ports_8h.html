bool ports_start ( const struct app_config *  cfg)

Starts the input and output interfaces.

Checks that the configured ports exist, builds the symmetric RSS key, creates the mbuf pool and starts both ports with one queue per worker. Call after rte_eal_init().

Parameters
cfgConfiguration with the port ids, queue count and RSS pattern.
Returns
true on success, false on failure (reason logged).

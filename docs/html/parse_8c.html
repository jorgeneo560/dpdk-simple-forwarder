enum parse_result parse_packet ( const uint8_t *  data,
size_t  len,
struct pkt_info *  info 
)

Reads the headers of an Ethernet frame.

Handles up to two VLAN tags (802.1Q, 802.1ad), IPv4 with options, and IPv6. Ports are read for TCP and UDP only; a non-first IPv4 fragment has none. IPv6 extension headers are not walked: proto is the first next-header and the ports stay 0 unless TCP/UDP follows the fixed header directly.

Parameters
dataStart of the frame.
lenBytes available in data.
infoReceives the extracted fields.
Returns
What kind of packet it is.

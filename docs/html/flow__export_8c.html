◆ flow_export_start()

bool flow_export_start ( const struct app_config *  cfg,
const unsigned int *  rx_lcores,
const unsigned int *  tx_lcores,
unsigned int  n 
)

Opens the CSV files and starts the writer thread.

Each queue gets two files, flow_stats_core_<lcore>.csv for its RX lcore and one for its TX lcore (next to the config file). Both receive the same rows, so the rows of a queue must be counted once, not twice. The workers never touch files: they fill a buffer and the writer thread writes it out.

Parameters
cfgConfiguration (file location, export interval for the log).
rx_lcoresRX lcore of each queue; queue i uses rx_lcores[i].
tx_lcoresTX lcore of each queue; queue i uses tx_lcores[i].
nNumber of queues.
Returns
true on success, false on failure (message logged).

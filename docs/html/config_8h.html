bool config_load ( struct app_config *  cfg)

Loads "flowfwd.conf" from the directory of the running binary.

Fills the defaults first, then overrides them from an INI-style file: "[section]" headers and "key = value" lines ('#' starts a comment). Unknown sections or keys and out-of-range values are errors.

Parameters
cfgReceives the settings and the path of the file.
Returns
true on success, false on failure (message printed to stderr).
